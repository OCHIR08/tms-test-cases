# Правила создания тест-кейсов для Навигатора дополнительного образования

## Общие правила:
- Стиль: повелительное наклонение ("Перейти", "Нажать", "Заполнить")
- Каждый шаг = одно действие + один ожидаемый результат
- Использовать скриншоты для каждого шага

## Нумерация:
- TC-001, TC-002, TC-003...
- Группировка по модулям: registration, authorization, programs, cabinet, activities, news

## Приоритеты:
- Critical: основные пользовательские сценарии (регистрация, авторизация, подача заявки)
- High: важные функции (просмотр каталога, личный кабинет)
- Medium: второстепенные функции (фильтры, поиск)
- Low: UI/UX детали

## Типы тест-кейсов:
1. Позитивные (успешные сценарии)
2. Негативные (валидации, ошибки)
3. Граничные случаи (edge cases)

## Ссылки на стенды:
- Формат URL: https://www.{СТЕНД}.navi.inlearno.info
- Использовать параметр {СТЕНД} для универсальности

## Тестовые данные:
- Использовать генератор: https://randomdatatools.ru/
- Формат email: test+{число}@example.com
- Пароль: минимум 8 символов, буквы + цифры
