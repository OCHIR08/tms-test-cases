# NAVI2E-40: Поделиться программой в соцсетях

| Параметр | Значение |
|---|---|
| **Приоритет** | Medium |
| **Серьезность** | Major |
| **Статус** | Actual |
| **Тип** | Other |
| **Автоматизация** | Not automated |
| **Роль** | Неавторизованный / авторизованный |
| **Тестовые планы** | Смоук Сайта НАВИ |

## Что изменено
- Заголовок упрощён (убраны альтернативы в скобках).
- Шаги атомарные: открытие, копирование, VK, MAX, ОК, закрытие, XSS в URL шаринга.
- Одноклассники вынесены отдельным шагом (были в описании, не в шагах).
- Внешний UI VK/MAX зафиксировать как **зависимый от провайдера** — проверять URL и передачу ссылки на программу, не внутреннюю вёрстку соцсети.

## Описание
Кнопка «Поделиться» на карточке программы: копирование URL и шаринг в MAX, ВКонтакте, Одноклассники. Доступно без авторизации.

## Предусловия
1. Есть опубликованная программа `/program/{id}-{slug}`.
2. Открыть `https://www.{СТЕНД}.navi.inlearno.info/program/{id}-{slug}` (авторизация не обязательна).
3. Разрешить всплывающие окна для проверки шаринга.

## Шаги

### Шаг 1
**Действие:**
Нажать «Поделиться» (иконка рядом с «В избранное», правый верх карточки).

**Ожидаемый результат:**
Модалка «Поделиться»: MAX, ВКонтакте, Одноклассники, иконка копирования URL, кнопка «X».

![step1](../screenshots/programs/program-share-modal.png)

### Шаг 2
**Действие:**
Нажать иконку копирования URL.

**Ожидаемый результат:**
Уведомление «Ссылка скопирована». Вставка в новую вкладку открывает ту же карточку `/program/{id}-{slug}` (без javascript: и XSS в буфере).

![step2](../screenshots/programs/program-share-copied.png)

### Шаг 3
**Действие:**
Нажать иконку «ВКонтакте».

**Ожидаемый результат:**
Новая вкладка `https://vk.ru/share.php?url=...` (или актуальный share-URL VK). В `url` — адрес текущей программы, экранированный. Скрипты из названия программы в URL не исполняются.

![step3](../screenshots/programs/program-share-vk.png)

### Шаг 4
**Действие:**
Вернуться на сайт, снова открыть «Поделиться», нажать «MAX».

**Ожидаемый результат:**
Вкладка `https://max.ru/...share...` (актуальный URL провайдера). Ссылка на программу передана в параметрах.

![step4](../screenshots/programs/program-share-max.png)

### Шаг 5
**Действие:**
Вернуться на сайт, нажать «Одноклассники».

**Ожидаемый результат:**
Открывается share OK (`ok.ru/dk` / актуальный URL). Параметр содержит URL программы.

![step5](../screenshots/programs/program-share-ok.png)

### Шаг 6
**Действие:**
Закрыть модалку «Поделиться» кнопкой «X».

**Ожидаемый результат:**
Модалка закрыта, страница программы на месте, «Поделиться» снова доступна.

![step6](../screenshots/programs/program_cart_screen_01.png)

## Общий ожидаемый результат
Ссылка копируется корректно, шаринг открывает внешние share-URL с адресом программы, XSS из данных карточки не исполняется.

## Критерии приемки
- [ ] Модалка содержит MAX, VK, OK, копирование, закрытие.
- [ ] Скопированный URL открывает ту же программу.
- [ ] Share-ссылки содержат URL карточки в закодированном виде.
- [ ] Закрытие модалки не ломает страницу.

## Параметры (data-driven)
| Параметр | Пример |
|----------|--------|
| URL программы | `/program/{id}-{slug}` |
| Copy | уведомление «Ссылка скопирована» |
