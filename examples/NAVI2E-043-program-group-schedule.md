| Параметр | Значение |
|---|---|

| **Серьезность** | Major |
| **Статус** | Actual |
| **Тип** | Other |

| **Роль** | Неавторизованный; сверка — администратор |

## Что изменено
- Исходник из 2 шагов расширен: выбор группы, вкладка «Группы», пустое расписание, XSS в кастомном тексте расписания.
- Явно: сверка с вкладкой «Расписание» диалога группы в админке.
- Границы: несколько слотов в день, выходные, период обучения.

## Описание
Расписание активной группы на публичной карточке совпадает с админкой (дни, время, период).

## Предусловия
1. Опубликованная программа с активной группой и заполненным расписанием: дни (ПН–ПТ или включая СБ/ВС), время (например 17:20–18:05), период (например 01.01.2026–13.12.2026).
2. Зафиксировать эталон в админке: группа → «Расписание».
3. URL: `https://www.{СТЕНД}.navi.inlearno.info/program/{id}-{slug}`.
4. Если групп несколько — знать, какая выбрана по умолчанию.

## Шаги

### Шаг 1
**Действие:**
Открыть карточку программы на сайте.

**Ожидаемый результат:**
В параметрах отображаются расписание (дни + время) и период освоения. Если есть вкладка «Группы» — список групп с расписанием доступен.

![step1](../screenshots/programs/program_cart_screen_03.png)

### Шаг 2
**Действие:**
Если на карточке есть селектор группы — выбрать группу из предусловия.

**Ожидаемый результат:**
Расписание и период обновляются под выбранную группу (не остаются от предыдущей).

![step2](../screenshots/programs/program-group-schedule-select.png)

### Шаг 3
**Действие:**
Сверить дни, время и период на сайте с вкладкой «Расписание» группы в админке.

**Ожидаемый результат:**
Полное совпадение: дни недели, интервал времени, даты начала и окончания. Нет сдвига часового пояса на ±1 день без причины.

![step3](../screenshots/programs/program-group-schedule-match.png)

### Шаг 4
**Действие:**
Открыть вкладку/раздел «Группы» (если есть) и сравнить строку расписания выбранной группы.

**Ожидаемый результат:**
Строка группы совпадает с блоком параметров карточки и с админкой.

![step4](../screenshots/programs/program-groups-tab-schedule.png)

### Шаг 5
**Действие:**
Найти (или завести) группу без расписания / с пустым слотом и открыть её на сайте. Проверить кастомный текст «Описание расписания», если в админке был XSS/`<script>`.

**Ожидаемый результат:**
Пустое расписание не показывает чужие слоты другой группы. Плейсхолдер/пустое состояние без 500. Скрипт в описании расписания не исполняется.

![step5](../screenshots/programs/program-schedule-empty-xss.png)

## Общий ожидаемый результат
Публичное расписание группы = админка. Смена группы обновляет слоты. Пустые данные и XSS безопасны.

## Критерии приемки
- [ ] Дни, время, период совпадают с админкой.
- [ ] Смена группы меняет расписание.
- [ ] Пустое расписание не подмешивает чужие данные.
- [ ] XSS в тексте расписания не исполняется.

## Параметры (data-driven)
| Параметр | Пример |
|----------|--------|
| Дни | ПН, ВТ, СР, ЧТ, ПТ |
| Время | 17:20 - 18:05 |
| Период | 01.01.2026 - 13.12.2026 |
