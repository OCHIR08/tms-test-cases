## Что изменено
- Шаги атомарные: открытие формы, валидное сохранение, проверка аватара по полу, пустые поля, XSS.
- SQL-шаг к `site_user_kids` убран из обязательных (опционально).
- Исправлены опечатки исходника («Всести», «Ивонвова»).
- Уточнено: редактирование доступно для **неподтверждённого** ребёнка.
- Скриншоты: placeholder `screenshots/cabinet/`.

## Описание
Проверка изменения профиля неподтверждённого обучающегося: сохранение валидных данных, валидация обязательных полей, XSS и корректность аватара по полу.

## Предусловия
1. Авторизоваться как родитель на `https://www.{СТЕНД}.navi.inlearno.info`.
2. В кабинете есть ребёнок в статусе **«Не подтвержден»** (восклицательный знак у фото). Если нет — выполнить NAVI2E-2.
3. Открыть кабинет, блок «ОБУЧАЮЩИЕСЯ».

## Шаги

### Шаг 1
**Действие:**
Возле профиля ребёнка нажать ссылку «ИЗМЕНИТЬ ДАННЫЕ».

**Ожидаемый результат:**
Открывается форма: «ФАМИЛИЯ» (обязательное), «ИМЯ» (обязательное), «ОТЧЕСТВО», «ДЕНЬ РОЖДЕНИЯ», «ПОЛ» (выпадающий список); чекбокс СВО выключен; кнопки «СОХРАНИТЬ» и «НАЗАД».

![step1](../screenshots/cabinet/edit-child-form.png)

### Шаг 2
**Действие:**
Ввести валидные значения: Фамилия — Иванова, Имя — Анна, Отчество — Петровна, День рождения — 12.12.2018, Пол — Женский. Нажать «СОХРАНИТЬ».

**Ожидаемый результат:**
Форма закрывается/возвращает в кабинет. Отображается новое ФИО. Аватар соответствует полу (девочка при «Женский»).

![step2](../screenshots/cabinet/edit-child-saved.png)

### Шаг 3
**Действие:**
Снова открыть «ИЗМЕНИТЬ ДАННЫЕ». Очистить «ФАМИЛИЯ», «ИМЯ», «ОТЧЕСТВО», «ДЕНЬ РОЖДЕНИЯ». Нажать «СОХРАНИТЬ».

**Ожидаемый результат:**
Данные не сохраняются. Предупреждения:
- ФАМИЛИЯ / ИМЯ: «Используйте кириллицу и проверьте наличие пробелов»;
- ДЕНЬ РОЖДЕНИЯ: «Введите корректный возраст».

![step3](../screenshots/cabinet/edit-child-empty-validation.png)

### Шаг 4
**Действие:**
В «ФАМИЛИЯ» ввести `<script>alert(1)</script>`, в «ДЕНЬ РОЖДЕНИЯ» — `00.00.0000`. Нажать «СОХРАНИТЬ».

**Ожидаемый результат:**
XSS не выполняется. Дата отклоняется. Профиль в списке остаётся с данными шага 2.

![step4](../screenshots/cabinet/edit-child-xss-date.png)

### Шаг 5
**Действие:**
Нажать «НАЗАД» (без сохранения невалидных значений).

**Ожидаемый результат:**
Возврат в кабинет. ФИО и аватар соответствуют шагу 2.

![step5](../screenshots/cabinet/edit-child-list-after-cancel.png)

## Опционально (не входит в smoke UI)
При доступе к БД: запись в `site_user_kids` для email родителя совпадает с шагом 2.

## Общий ожидаемый результат
Валидные изменения профиля ребёнка сохраняются и отражаются в UI (включая аватар). Пустые обязательные поля, некорректная дата и XSS не сохраняются.

## Критерии приемки
- [ ] Форма редактирования содержит актуальные поля и кнопки.
- [ ] Валидное сохранение обновляет ФИО и аватар.
- [ ] Пустые обязательные поля показывают ожидаемые тексты ошибок.
- [ ] XSS не исполняется, карточка ребёнка не портится.
- [ ] «НАЗАД» не применяет несохранённые невалидные данные.
