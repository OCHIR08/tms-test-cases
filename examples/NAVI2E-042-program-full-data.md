# NAVI2E-42: Программа. Отображение описания и всех данных на публичном сайте

| Параметр | Значение |
|---|---|
| **Приоритет** | Medium |
| **Серьезность** | Major |
| **Статус** | Actual |
| **Тип** | Other |
| **Автоматизация** | Not automated |
| **Роль** | Неавторизованный; сверка с админкой — администратор |
| **Тестовые планы** | Смоук Сайта НАВИ |

## Что изменено
- Шаги атомарные; сверка админка ↔ сайт без emoji-чеклиста в ожидаемом результате.
- Добавлены XSS/HTML в описании (в админке заранее заведен безопасный и небезопасный контент) и проверка, что сырой HTML/скрипт не исполняется.
- Адаптив: нет горизонтального скролла на узкой ширине.
- Скриншоты: `screenshots/programs/`.

## Описание
Полная сверка карточки программы на сайте с админкой: описание с форматированием, параметры, педагоги, отзывы, организатор.

## Предусловия
1. В админке `https://booking.{СТЕНД}.navi.inlearno.info` опубликована программа с заполненными: название, краткое и полное описание (заголовки, абзацы, списки), обложка, возраст, форма обучения, ОВЗ, адрес, муниципалитет, расписание, МТБ, цена, 1–2 педагога, разделы «Содержание», «Цели», «Результат», «Особые условия».
2. Зафиксировать эталон (скрин/заметки) до выхода на сайт.
3. URL сайта: `https://www.{СТЕНД}.navi.inlearno.info/program/{id}-{slug}`.
4. Желательно: в описании есть экранируемая строка `<script>alert(1)</script>` или HTML-теги — проверить, что на сайте они не исполняются.

## Шаги

### Шаг 1
**Действие:**
В админке открыть карточку программы и зафиксировать: название, краткое/полное описание, возраст, форму обучения, адрес, муниципалитет, ФИО педагогов.

**Ожидаемый результат:**
Эталон записан. Дальнейшие шаги сравниваются только с ним.

![step1](../screenshots/programs/admin-program-description.png)

### Шаг 2
**Действие:**
Открыть карточку на публичном сайте.

**Ожидаемый результат:**
Шапка категории; обложка; название; рейтинг; выбор группы; артикул, преподаватель, возраст, период, расписание, адрес, форма обучения, план приёма; стоимость; «Записаться» / «Запись закрыта»; организатор; «В избранное»; «Поделиться».

![step2](../screenshots/programs/program_cart_screen_01.png)

### Шаг 3
**Действие:**
Проверить блок «О программе».

**Ожидаемый результат:**
Текст совпадает с админкой. Заголовки жирные, абзацы и списки сохранены. Сырой HTML не торчит как текст ошибки вёрстки и **не** исполняет script. Нет горизонтального скролла, текст в границах колонки.

![step3](../screenshots/programs/program_cart_screen_02.png)

### Шаг 4
**Действие:**
Прокрутить вниз: описание расписания, МТБ, описание цены, преподаватели, отзывы, анкеты.

**Ожидаемый результат:**
Тексты на месте. Карточки педагогов: фото или плейсхолдер, ФИО, ссылка «Все программы педагога →». Вкладки «Отзывы» / «Анкеты» открываются.

![step4](../screenshots/programs/program_cart_screen_05.png)

### Шаг 5
**Действие:**
Поэлементно сверить параметры сайта с эталоном шага 1.

**Ожидаемый результат:**
Совпадают: название, возраст, форма обучения, адрес, муниципалитет, расписание, период освоения, план приёма.

![step5](../screenshots/programs/program_cart_screen_03.png)

### Шаг 6
**Действие:**
Проверить блок организатора справа.

**Ожидаемый результат:**
Название, email, телефон, сайт совпадают с админкой. «Все программы организации» ведёт на список программ этого организатора. `javascript:` в поле «сайт» не исполняется (ссылка относительная/https либо не кликабельна).

![step6](../screenshots/programs/program_cart_screen_04.png)

## Общий ожидаемый результат
Публичная карточка полно и безопасно отражает данные админки, форматирование сохранено, XSS из описания/сайта организации не исполняется.

## Критерии приемки
- [ ] Все блоки карточки на месте.
- [ ] Описание и параметры = админка.
- [ ] Педагоги, отзывы, анкеты открываются.
- [ ] HTML/XSS не исполняется, вёрстка не ломается.
