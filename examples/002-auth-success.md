# TC-002: Авторизация: успешный вход с корректными логином и паролем (сайт)

## Описание
Позитивное тестирование авторизации на публичном сайте навигатора дополнительного образования.
Проверка входа ранее зарегистрированного и подтвержденного пользователя.

## Предусловия
1. Иметь подтвержденный аккаунт пользователя 
2. Запомнить логин и пароль созданного пользователя.
3. Выйти из аккаунта на сайте, если авторизован.
4. Находиться на главной странице сайта https://www.{СТЕНД}.navi.inlearno.info

## Шаги

### Шаг 1
**Действие:**
На главной странице сайта нажать кнопку "ВХОД".

**Ожидаемый результат:**
Открывается модальное окно авторизации с полями "Ваш EMAIL" и "Ваш ПАРОЛЬ", кнопка "ВОЙТИ" неактивна.

![step1](../screenshots/authorization/auth_02_login_modal.png)

### Шаг 2
**Действие:**
- В поле "Ваш EMAIL": ввести EMAIL который ты подготовил по предусловию
- В поле "Ваш ПАРОЛЬ": ввести ПАРОЛЬ который ты подготовил по предусловию
- Нажать кнопку "ВОЙТИ"

**Ожидаемый результат:**
1. Модальное окно закрывается.
2. Происходит перенаправление на главную страницу сайта.
3. В правом верхнем углу вместо кнопок "РЕГИСТРАЦИЯ" и "ВХОД" отображается ФИО пользователя.
4. Пользователь успешно авторизован в системе.

![step2](../screenshots/authorization/auth_05_main_page_main_page_after_logging_in.png)

## Общий ожидаемый результат
Успешная аутентификация с валидными учетными данными.
