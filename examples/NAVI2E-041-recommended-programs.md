| Параметр | Значение |

| **Серьезность** | Major |

| **Тестовые планы** | Смоук Сайта НАВИ |

## Комментарий
**Требует подтверждения у аналитика.** В исходной выгрузке: «ЕСТЬ ВЕРОЯТНОСТЬ ЧТО ЭТОГО ФУНКЦИОНАЛА УЖЕ НЕТ». Блок рекомендаций на карточке программы может быть снят или заменён ссылкой «Все программы организатора». Кейс не включать в смоук, пока аналитик не подтвердит наличие блока.

## Что изменено
- Статус оставлен `Obsolete`.
- Шаги сохранены как чек-лист **верификации существования** функционала (не как обязательный smoke).
- Добавлены проверки: только опубликованные карточки, без дубля текущей программы, XSS в названиях рекомендаций.

## Описание
Исторический сценарий блока рекомендуемых программ на карточке `/program/{id}-{slug}`. Использовать только для подтверждения, жив ли UI.

## Предусловия
1. Опубликованная программа на сайте.
2. У того же организатора есть другие опубликованные программы.
3. Открыть `https://www.{СТЕНД}.navi.inlearno.info/program/{id}-{slug}`.

## Шаги (верификация, не smoke)

### Шаг 1
**Действие:**
Открыть карточку и прокрутить вниз до конца страницы.

**Ожидаемый результат:**
Если функционал жив — блок рекомендаций и/или «Все программы организатора» с карточками. Если блока нет — зафиксировать отсутствие и **не заводить дефект** до ответа аналитика; кейс остаётся Obsolete.

![step1](../screenshots/programs/program-recommendations.png)

### Шаг 2
**Действие:**
При наличии блока проверить состав карточек.

**Ожидаемый результат:**
Только опубликованные программы; название, обложка, ключевые параметры; текущая программа не дублируется. XSS в названии соседней программы не исполняется.

![step2](../screenshots/programs/program-recommendations-cards.png)

### Шаг 3
**Действие:**
Кликнуть по рекомендованной карточке.

**Ожидаемый результат:**
Переход на её `/program/{id}-{slug}` без 500.

![step3](../screenshots/programs/program-recommendations-click.png)

### Шаг 4
**Действие:**
Вернуться назад. Перейти по «Все программы организатора» (если ссылка есть).

**Ожидаемый результат:**
Страница организации со списком опубликованных программ организатора.

![step4](../screenshots/programs/organization-programs.png)

## Общий ожидаемый результат
До подтверждения аналитика кейс не является критерием релиза. Если блок найден — сценарий выше должен выполняться.

## Критерии приемки
- [ ] Аналитик подтвердил: блок есть / блока нет / заменён другой UI.
- [ ] После подтверждения статус сменить на Actual или удалить из плана.
- [ ] Не включать в смоук, пока статус Obsolete.
