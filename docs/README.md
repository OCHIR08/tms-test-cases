# Документация проекта TMS Test Cases

Эта папка содержит документацию для ИИ-агента по генерации тест-кейсов.

## Структура
- `requirements-*.md` — требования по модулям
- `business-rules-*.md` — бизнес-правила и валидации
- `changelog.md` — история изменений системы
- `api-spec.md` — описание API (если есть)

## Как использовать
ИИ-агент читает эти файлы для понимания контекста при генерации тест-кейсов.

## Статус
В процессе заполнения.
