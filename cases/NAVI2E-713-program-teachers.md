# NAVI2E-713: Сайт. Программа. Просмотр педагогов

## Описание
Позитивное тестирование отображения педагога на карточке опубликованной программы. Mobile First.

## Предусловия
- На сайте есть опубликованная программа.
- В группе этой программы указан педагог.
- Открыта карточка программы.

## Шаги

### Шаг 1
**Действие:**
Просмотреть параметры выбранной группы.

**Ожидаемый результат:**
В параметрах группы указан преподаватель.

![step1](../screenshots/programs/prog_05_program_card_details.png)

### Шаг 2
**Действие:**
Открыть страницу этого педагога из карточки программы.

**Ожидаемый результат:**
Отображаются фото, имя педагога, достижения и группы, в которых он преподаёт.

## Общий ожидаемый результат
Педагог виден в параметрах группы, а его страница показывает достижения и группы.
