# NAVI2E-853: Сайт. Мероприятия. Список на выбранную дату

## Описание
Позитивное тестирование перехода из календаря к списку мероприятий дня и возврата в календарь. Mobile First.

## Предусловия
- На дату в текущем месяце есть опубликованные мероприятия, у дня в календаре есть счётчик.
- Открыт календарь мероприятий.

## Шаги

### Шаг 1
**Действие:**
Нажать день со счётчиком мероприятий.

**Ожидаемый результат:**
Открывается список мероприятий этой даты. Число карточек совпадает со счётчиком дня. У карточки есть краткое описание и кнопка «Подробнее». Доступен возврат в календарь.

![step1](../screenshots/activities/act_04_activities_by_date.png)

### Шаг 2
**Действие:**
Нажать «Подробнее» у мероприятия из списка.

**Ожидаемый результат:**
Открывается карточка мероприятия. Дата проведения совпадает с выбранным днём.

![step2](../screenshots/activities/act_05_activity_card_full.png)

### Шаг 3
**Действие:**
Вернуться к списку дня и нажать «Вернуться в календарь мероприятий».

**Ожидаемый результат:**
Открывается календарь того же месяца.

![step3](../screenshots/activities/act_03_calendar_current_month.png)

## Общий ожидаемый результат
По дню календаря открывается список его мероприятий, из списка открывается карточка, а возврат ведёт в календарь того же месяца.
