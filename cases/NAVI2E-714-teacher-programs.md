# NAVI2E-714: Сайт. Программа. Все программы педагога

## Описание
Позитивное тестирование списка опубликованных программ педагога. Mobile First.

## Предусловия
- Педагог указан в группах нескольких опубликованных программ.
- Открыта страница этого педагога.

## Шаги

### Шаг 1
**Действие:**
Открыть список программ педагога.

**Ожидаемый результат:**
В списке есть опубликованные программы, в группах которых указан этот педагог.

### Шаг 2
**Действие:**
Открыть карточку одной программы из списка.

**Ожидаемый результат:**
Открывается карточка выбранной программы.

![step2](../screenshots/programs/prog_05_program_card_full.png)

## Общий ожидаемый результат
Со страницы педагога открывается карточка его опубликованной программы.
