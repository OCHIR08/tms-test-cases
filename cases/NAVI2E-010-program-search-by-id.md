# NAVI2E-010: Сайт. Программы. Поиск по идентификатору

## Описание
Позитивное тестирование поиска опубликованной программы по уникальному идентификатору. Mobile First.

## Предусловия
- На сайте опубликована программа, известен её уникальный идентификатор.
- Открыта главная страница публичного сайта.

## Шаги

### Шаг 1
**Действие:**
В строку поиска ввести уникальный идентификатор опубликованной программы.

**Ожидаемый результат:**
В выпадающем списке появляется эта программа.

![step1](../screenshots/programs/prog_01_main_page.png)

### Шаг 2
**Действие:**
Выбрать программу в выпадающем списке.

**Ожидаемый результат:**
Открывается карточка выбранной программы.

![step2](../screenshots/programs/prog_05_program_card_full.png)

## Общий ожидаемый результат
По уникальному идентификатору программа находится в выпадающем списке поиска и открывается её карточка.
