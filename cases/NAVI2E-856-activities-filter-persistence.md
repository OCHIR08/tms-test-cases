# NAVI2E-856: Сайт. Мероприятия. Фильтр сохраняется при смене месяца

## Описание
Позитивное тестирование сохранения фильтра календаря при переходе между месяцами. Mobile First.

## Предусловия
- Опубликованы мероприятия в текущем и соседнем месяце.
- В календаре применён фильтр, например по разделу.
- Открыт календарь мероприятий.

## Шаги

### Шаг 1
**Действие:**
Перейти к следующему месяцу стрелкой или списком месяца.

**Ожидаемый результат:**
Календарь показывает следующий месяц. Выбранный фильтр остаётся применённым, счётчики учитывают его.

![step1](../screenshots/activities/act_03_calendar_current_month.png)

### Шаг 2
**Действие:**
Вернуться к предыдущему месяцу.

**Ожидаемый результат:**
Календарь показывает исходный месяц. Фильтр по-прежнему применён, счётчики соответствуют отфильтрованным мероприятиям.

## Общий ожидаемый результат
Применённый фильтр сохраняется при переходе вперёд и назад по месяцам.
