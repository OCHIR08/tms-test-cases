# NAVI2E-852: Сайт. Программа. Группа без расписания

## Описание
Проверка карточки опубликованной программы, у группы которой не заполнено расписание. Mobile First.

## Предусловия
- Есть опубликованная программа с группой без дней, времени и периода освоения.
- Открыта карточка этой программы.

## Шаги

### Шаг 1
**Действие:**
Открыть параметры этой группы.

**Ожидаемый результат:**
Карточка открывается без сбоя вёрстки. Расписание и период освоения пустые или помечены как не указанные. Остальные заполненные параметры группы видны.

## Общий ожидаемый результат
Отсутствие расписания не ломает карточку программы: пустые поля расписания и периода отображаются без ошибок.
