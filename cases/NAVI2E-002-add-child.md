# NAVI2E-002: Сайт. Личный кабинет. Добавление профиля обучающегося

## Описание
Позитивное тестирование создания профиля обучающегося в личном кабинете родителя. Mobile First.

## Предусловия
- Пользователь авторизован на сайте.
- Открыта главная страница публичного сайта.

## Шаги

### Шаг 1
**Действие:**
Нажать на ФИО пользователя в шапке сайта.

**Ожидаемый результат:**
Открывается личный кабинет.

![step1](../screenshots/cabinet/cab_02_lk_cabinet.png)

### Шаг 2
**Действие:**
Открыть раздел «Обучающиеся».

**Ожидаемый результат:**
Отображается раздел «Обучающиеся» и кнопка «Добавить профиль обучающегося».

![step2](../screenshots/cabinet/cab_06_lk_students.png)

### Шаг 3
**Действие:**
Нажать кнопку «Добавить профиль обучающегося».

**Ожидаемый результат:**
Открывается форма добавления профиля. Доступна кнопка «Назад».

![step3](../screenshots/cabinet/cab_06_lk_students_add_student_profile.png)

### Шаг 4
**Действие:**
Заполнить обязательные поля валидными данными и выбрать пол из списка.

**Ожидаемый результат:**
Введённые значения отображаются в форме, кнопка «Добавить профиль обучающегося» доступна.

### Шаг 5
**Действие:**
Нажать кнопку «Добавить профиль обучающегося».

**Ожидаемый результат:**
Профиль создан. В разделе «Обучающиеся» отображаются имя, возраст и иконка выбранного пола. У профиля есть признак неподтверждённых данных и кнопка «Изменить данные».

![step5](../screenshots/cabinet/cab_06_lk_students.png)

## Общий ожидаемый результат
В кабинете родителя создан неподтверждённый профиль обучающегося с введёнными данными.
