# NAVI2E-427: Сайт. Блог. Поделиться записью

## Описание
Позитивное тестирование кнопок «Поделиться» на странице записи блога. Mobile First.

## Предусловия
- Открыта опубликованная запись блога.

## Шаги

### Шаг 1
**Действие:**
Найти на странице записи блок «Поделиться».

**Ожидаемый результат:**
Отображаются кнопки социальных сетей.

![step1](../screenshots/news/news_03_news_card.png)

### Шаг 2
**Действие:**
Нажать кнопку одной из социальных сетей.

**Ожидаемый результат:**
Открывается окно этой сети для публикации ссылки на запись.

## Общий ожидаемый результат
С страницы записи блога можно открыть окно публикации ссылки в социальной сети.
