# NAVI2E-855: Сайт. Мероприятия. Фильтр календаря по разделу

## Описание
Позитивное тестирование пересчёта календаря после фильтра по разделу. Mobile First.

## Предусловия
- Опубликованы мероприятия разных разделов.
- Открыт календарь мероприятий.

## Шаги

### Шаг 1
**Действие:**
В панели фильтрации выбрать раздел и нажать «Применить».

**Ожидаемый результат:**
Счётчики дней пересчитаны по мероприятиям выбранного раздела. «Сбросить всё» доступно.

![step1](../screenshots/activities/act_03_calendar_current_month.png)

### Шаг 2
**Действие:**
Открыть день, у которого после фильтра остался счётчик.

**Ожидаемый результат:**
В списке даты только мероприятия выбранного раздела. Число карточек совпадает со счётчиком дня.

![step2](../screenshots/activities/act_04_activities_by_date.png)

## Общий ожидаемый результат
После фильтра по разделу календарь и список дня показывают только мероприятия этого раздела.
