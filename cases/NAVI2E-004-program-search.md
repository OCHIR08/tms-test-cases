# NAVI2E-004: Сайт. Программы. Поиск по строке

## Описание
Позитивное тестирование поиска опубликованной программы по точному названию. Mobile First.

## Предусловия
- На сайте опубликована программа, известно её точное название.
- Открыта главная страница публичного сайта.

## Шаги

### Шаг 1
**Действие:**
Найти строку поиска программ.

**Ожидаемый результат:**
Строка поиска доступна.

![step1](../screenshots/programs/prog_01_main_page.png)

### Шаг 2
**Действие:**
Ввести точное название опубликованной программы.

**Ожидаемый результат:**
В выпадающем списке появляется эта программа.

### Шаг 3
**Действие:**
Выбрать программу в выпадающем списке.

**Ожидаемый результат:**
Открывается карточка выбранной программы.

![step3](../screenshots/programs/prog_05_program_card_full.png)

## Общий ожидаемый результат
По точному названию программа находится в выпадающем списке поиска и открывается её карточка.
